Each folder has the solution notebook (with saved outputs), the Python helper modules, and a README that says which data the notebook expects.

## Notes
- Course datasets are not redistributed here. See each project README.
- Starter helpers and tests are Udacity course scaffolding.
- Any API key has been replaced by `YOUR_QUANDL_API_KEY`. Add your own to rerun the data download.
- The package versions in `requirements.txt` are from 2018-era course environments (Python 3.6) and will not install cleanly on current Python.
